# ForgeFlow 0.4.0

This breaking pre-1.0 release makes Acceptance Evidence part of optional Story
readiness. Before `scripts/story-check --ready` succeeds, every checkbox AC
must map to one exact evidence method, fixture or precondition, and expected
observation.

Upgrade templates with `./scripts/bootstrap --upgrade /path/to/repository`,
manually reconcile the repository-owned `AGENTS.md`, and add the map to every
Story checked with `--ready`. The checker validates the declaration only: it
does not execute tests or commands, parse test sources, approve Human Review,
or replace `make verify`.

Default `scripts/story-check`, Repository Doctor, bootstrap command forms, and
the repository-owned `make verify` interface remain unchanged. See the full
migration and rollback guidance in [Protocol Versioning](../../protocol/versioning.md).

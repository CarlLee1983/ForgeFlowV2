# ForgeFlow 0.7.0

An optional architecture decision root for repositories that already keep ADRs
outside `specs/decisions/`. **Additive**: existing Story-check invocations keep
their current decision root and verdicts.

## What changed

`scripts/story-check` now accepts `FORGEFLOW_DECISIONS_ROOT`. Set it to the
directory that contains the repository's ADR files for the invocation:

```sh
FORGEFLOW_DECISIONS_ROOT=docs/adr ./scripts/story-check
```

The selected directory is the only decision root for that invocation. The
checker retains its existing `ADR-<digits>` or `ADR-<digits>-<slug>` lookup,
duplicate, readability, and usable-status checks. An unset or empty variable
continues to use `specs/decisions/` relative to the Story collection.

Risk-reason diagnostics and the Story template now state the required shape:
one non-empty same-line backticked signal, such as `versioned-surface`. Prose
or a closing backtick on another line is invalid.

## Upgrade

No migration is required. Keep an existing `docs/adr/` (or other ADR directory)
where it is, and set `FORGEFLOW_DECISIONS_ROOT` in the local command or CI step
that runs `scripts/story-check`. Do not set it when the repository uses the
default `specs/decisions/` collection.

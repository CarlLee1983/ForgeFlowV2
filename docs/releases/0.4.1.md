# ForgeFlow 0.4.1

`0.4.1` adds the optional Engineering Guidance Layer Phase 1. Fresh bootstrap
and explicit `--force` install four repository-readable baseline files under
`guidance/`; existing Stories and adoptions remain compatible.

`--upgrade` deliberately never reads or writes repository/team-owned Guidance.
Adopters who want the baseline copy it manually and reconcile it with their
existing decisions and practices. Repository Doctor reports an absent directory
as optional/legacy-compatible, a present partial baseline as drift, and unsafe
paths as errors. Guidance is advisory, selective, and never replaces Story
intent, `make verify`, or Human Review.

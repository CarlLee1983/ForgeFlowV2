# Superseded TypeScript Tooling Design Artifacts

Files in this directory are retained design evidence. They are not current
PraxisBound contracts and must not be used to validate CLI output.

`result-envelope-v1-planning-draft.schema.json` described the pre-TST-002
planning envelope. TST-002 implemented a different, smaller `1.0.0` envelope;
ADR-011 makes that implementation the canonical schema source before the first
npm publication.
